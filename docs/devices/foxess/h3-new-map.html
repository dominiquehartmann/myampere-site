FoxESS H3, register map of newer firmware

Not official manufacturer information: compiled by the OpenAmpere contributors, possibly incomplete or wrong. Changing inverter settings can affect warranty and grid connection rules. No affiliation with FoxESS or EKD, not legal advice. See Device knowledge.

Applies to: FoxESS H3 with newer firmware, H3 Smart, H3 Pro (probably the E3) · Sold as: see h3.md · OpenAmpere: driver foxess, register map foxess_h3_new · Support: display and control · Confirmed on a real device: partly (reading and control on an H3 with newer firmware; H3 Smart and H3 Pro not)

Family facts (detection, connection limits, remote control behaviour, decisions on grid charging) are on h3.md; the older map is on h3-legacy-map.md.

Summary

  • Chosen when the energy counters at 39601 answer. Measurement registers are input registers (FC04) by default; OpenAmpere falls back to FC03 because the sources disagree.
  • Has total registers for grid, house and PV power, up to four PV strings and three MPPT trackers, a second battery module (BMS2) and cell temperatures.
  • Energy counters in 0.01 kWh.
  • Settings and control are holding registers: work mode 49203, SoC limits 46609–46611, remote control 46001–46004, export limit 46616–46617.
  • Reading confirmed on a real H3 (#11, #16), control confirmed (#196); the exact variant (H3, H3 Smart, H3 Pro or E3) is not stated in these reports.

Behaviour

FactStatusSource
Reading with this map works on a real H3 (#11, #16). Not every register above is checked one by one; the reports name the exact variant only as "H3 / H3 Smart / H3 Pro / E3".confirmed#11, #16, #111, #173, #185
Control with this map works on a real system: work mode, backup reserve and limits, remote control for grid charging, export limit (earlier only partly confirmed, #25).confirmed#25, #196, #197
39141 is in 0.1 °C like the other temperatures: raw 452 means 45.2 °C, matching a second readout tool. Read without the factor, it exceeded the 120 °C plausibility limit and was dropped.confirmed#11, #26
37611 read about 15 °C above the cell temperatures on one owner's system and matched what another dashboard calls "BMS1 internal": it is the BMS electronics.confirmed#16, #41
The off-grid bit (39065 bit 0) was set in a single reading while the system exported several kW, followed by minutes without readings.confirmed#89, #90
The second battery module registers (38309, 38315, 38316) read 0 or the block is rejected when there is no second module.deriveddriver.py, diagnostics.py
The export limit register 46616 is rejected with "illegal address" on devices without it.deriveddriver.py
One device read about 60000 W in 46616, far above its rated power. Probably the value for "no limit set"; not confirmed against the manufacturer's app.opendiagnostics report, #413
On one owner's H3, 46001 stayed 1 with 46002 = 180 and 0 W long after the watchdog time; see h3.md.confirmed#141, #142
Reading 46001 right after writing 0 may show a delayed value; the delay is not quantified on a device (OpenAmpere polls for a few seconds). Under remote control a new backup reserve is taken over a few seconds late (#322).open#142, #322
Energy counters count in 0.01 kWh (10 Wh) units. Suspected: some newer firmware steps only by 0.1 kWh.open#194, #195

Decisions in OpenAmpere

DecisionWhyIssue/PR
Blocks 37002, 38309, 39063, 39118, 39141, 39279 and 39327 are optional: a rejected one is skipped.Models without a second battery, MPPT details or other parts.registers.py
PV inputs: the MPPT trackers (up to 3) are preferred because they correspond to module arrays; otherwise PV1–PV4. PV total from 39118, otherwise the sum of the inputs.MPPTs match the owner's arrays.driver.py
SoC and battery temperatures are dropped when 37002 is 0; BMS2 temperatures are dropped when all are 0.No battery or no second module connected.driver.py
Grid power is negated to + = import.OpenAmpere's common sign convention.driver.py
If 46616 is rejected, the export limit is reported as not supported.Not every device has the register.driver.py
OpenAmpere's remote command pattern is 46001 = 5 (or 1, see h3.md) and 46002 = 180, with the power in 46003–46004; it recognises its own commands by it, 1 / 180 s left over by older versions included (#509).Release only what OpenAmpere started.#141, #142
Diagnostics (new map only): check the optional blocks 38309 and 39327; compare a 24-register block read at 37609 with single reads of 37609, 37612, 37624; check the scale of 39141 (raw values up to 90 count as ambiguous, the report shows raw and scaled value); show 37002 as yes/no.Finds block-read and scaling problems from a shared report.diagnostics.py, #19, #26, #44
Diagnostics read 46616 and report it rounded to 100 W with only the high word, not the raw words.The exact limit (60 % or 70 % of the kWp) reveals the system size.#149, #150
Diagnostics show a value above the rated power as information ("probably no limit set"), only a negative value as a warning.A device reported about 60000 W, far above its rated power; more than the rated power cannot be exported anyway.#413
Diagnostics read 46001–46004 as one FC03 block and tell three cases apart: off, on by OpenAmpere (charging or a leftover it switches off itself), on by another device (warning with the values). A background job reads the block read-only every 5 minutes to say how long it has been on. The check and the report decode 46001 (target, sign) and read 46007 on its own: a running countdown while OpenAmpere sends nothing means another writer or values restored after a restart, 0 while on means the watchdog left the switch on. 0 W is explained per target: the battery rests (target battery); the house runs from the grid and PV is curtailed once the battery is full (target AC) (#509).Shows who controls the battery, e.g. the previous smartbox.#126, #127, #135, #136, #142

Open questions

  • Which register map the E3 uses (model string at 30000).
  • FC03 or FC04 for the measurement registers: foxess_modbus reads this map with FC03, other sources with FC04 (conflict; OpenAmpere tries both).
  • Where the remote control addresses come from is not named in #126 and #127; docs/registers.md credits foxess_modbus for the map.
  • Whether the H3 Smart and H3 Pro behave the same; whether all variants have the export limit at 46616 (foxess_modbus names only the H3 Smart).
  • Meaning of 20162, which the previous smartbox was reported to write.
  • Unit of the remaining capacity at 37632.
  • Whether some firmware counts in 0.1 kWh steps (#194).
