General

What is myAmpere?

A free, local app that reads the values of your solar system and battery directly from the inverter. It runs on your own computer on the home network and shows the values in the browser or as an app on the smartphone.

What does myAmpere cost?

Nothing. There are no subscriptions and no ads. You only need a computer that runs on the home network.

Where does my data go?

The values of your system stay on your computer at home. myAmpere does not send usage data to the developer and needs no account.

Which computer runs myAmpere?

A computer with Linux, Docker and Docker Compose, for example a Raspberry Pi, a small server or a virtual machine. The installation is described on the start page.

My system

Which devices are supported?

The FoxESS H3 and the SAJ H2 and HS2 storage systems are supported. Which devices are confirmed and what each one reads and controls is on the devices page.

Do I have to change anything on the inverter?

Modbus TCP must be switched on and the inverter must be reachable on the home network. You find the device address in the inverter's settings. For FoxESS it is usually 247.

Can I reach my data from outside as well?

Yes, through your own Tailscale network. The access is set up in the app under More → Access from outside.

Never expose the app directly to the internet with a port forward. Use Tailscale or the VPN of your router.

How do I back up my data or move to a new computer?

Under More → Data & backup you download a backup, which you can also encrypt with a password. On the new computer you restore it on the same page.

Safety

Can I break something with myAmpere?

After installation myAmpere only reads. Changes to the inverter are possible only when you switch the master switch to Test or Active. In test mode it only logs.

Note the current values before you change anything, and change only what you understand.

May I change the feed-in limit?

Only within what applies to your system. Your grid operator and the legal situation decide which rule applies. The grid operator can answer questions.

Is the use free and without warranty?

Yes. The software is under the MIT license and provided without warranty. Notes on the grid, feed-in and tariffs are not legal advice.

Help and contributing

Where do I get help with setup?

The steps and troubleshooting are in the README in the repository, in German in README.de.md. The diagnostics in the app help with connection problems.

How do I update myAmpere?

In the myampere folder run git pull and then docker compose up -d --build. Afterwards run the diagnostics once.

Where do I report a bug or a request?

As an issue in the repository on GitHub. For devices a diagnostics report from the app helps; personal data is masked in it.
