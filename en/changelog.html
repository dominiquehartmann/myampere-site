Versions

Changelog

What changed in every version, newest first, taken directly from development. You install an update in the app under More → About OpenAmpere.

Version 1.18.0

November 8, 2026

New

  • A tap on the tab you are on now scrolls its page back to the top.

Fixed

  • Passkey login is removed for now. It will return later through a dedicated app.
  • The notice about a new version of myAmpere names the version of myAmpere again, not the one of OpenAmpere.

Version 1.17.2

November 7, 2026

New

  • The app is now called myAmpere (previously “OpenAmpere Plus”). The original project it is built on is still called OpenAmpere.

Version 1.17.1

November 7, 2026

New

  • New app icon: a ray crown with a lightning bolt instead of plain rays.

Version 1.17.0

November 6, 2026

New

  • The notice “A new version of myAmpere is installed” now names the version in brackets, so you can see which one is running.

Version 1.16.0

November 6, 2026

New

  • Devices, battery card: “Charge battery now” charges the battery with the charging power from “Grid charging” up to the state of charge you choose. The charge ends there by itself, or you cancel it with “Cancel quick charge”. “Grid charging” must be switched on for it.

Version 1.15.0

November 6, 2026

New

  • Start page: the hint about power per string and temperatures is now a link to More → My system, like the link to More → Connection under Devices.

Version 1.14.1

November 6, 2026

Fixed

  • Evaluation: the heat pump (EEBus) no longer appears twice, because its power is already in the chart under Devices. Its offers and actions stay visible below it.

Version 1.14.0

November 6, 2026

New

  • Access protection: sign-ins from unknown devices and repeated failed attempts send a notification, with the source (address) and the device. The latest sign-ins and failed attempts are listed under More → Access protection. You set the number, the time window and the repeat of the warning under Notifications.

Version 1.13.0

November 6, 2026

New

  • New logo: app icon and favicons with twelve rays in the project’s green. It appears on the home screen and in the browser tab.

Version 1.12.0

November 6, 2026

New

  • Wallbox charging plan: a set charging plan can now be deleted, also from the open form with “Delete charging plan”.

Version 1.11.19

November 6, 2026

Fixed

  • Wallbox charging plan: after “Set charging plan” the form stays open. The button is active again only once you change something.

Version 1.11.18

November 6, 2026

Fixed

  • Wallbox charging plan with repetition: the weekday buttons showed the wrong day. Monday and Tuesday are right now, and Sunday no longer starts the week.

Version 1.11.17

November 6, 2026

Fixed

  • Wallbox charging plan: the target and time overlapped on narrow screens, because the slider next to the time field had too little room. They now stack on top of each other there.

Version 1.11.16

November 6, 2026

Fixed

  • Wallbox charging plan, plan preview: now shows OpenAmpere's own electricity prices (Tibber/the exchange) instead of waiting for evcc's own price source, which often is not even set up there.

Version 1.11.15

November 6, 2026

New

  • Wallbox: the charging plan can now also set an optimization strategy (cheapest/continuous), late charging right before departure, and a plan that repeats on chosen weekdays – as in evcc itself. Plus a plan preview with the price of each time window, readable by hovering over it.

Version 1.11.14

November 6, 2026

Fixed

  • Charging plan “grid charging”: the solar forecast for today and tomorrow differed from More → Solar forecast, because it was computed from the charging plan, which already has “share of the solar forecast” applied. Now shows the same figures as More → Solar forecast.

Version 1.11.13

November 6, 2026

New

  • Charging plan “grid charging”: now also shows the solar forecast for today and tomorrow in kWh (like More → Solar forecast), and the outdoor temperature curve is now green instead of orange.

Version 1.11.12

November 6, 2026

New

  • Charging plan “grid charging”: the chart with the solar forecast and expected consumption now also shows the outdoor temperature forecast. For that, it is now always fetched once a location is entered for the solar forecast – no longer only while “weather-dependent consumption” is on.

Version 1.11.11

November 5, 2026

New

  • Passkey login: More → Access protection can now also set up a passkey (Face ID, a fingerprint, Windows Hello or a security key instead of a password). Only works through a name (e.g. Tailscale or a .fritz.box name) and a secured connection (HTTPS), not through the bare IP address in the home network.

Version 1.11.10

November 2, 2026

New

  • Two-factor authentication: More → Access protection can now also require a code from an authenticator app on top of the password (no QR code: the key is shown for manual entry), with recovery codes in case the phone is lost.

Version 1.11.9

November 2, 2026

New

  • Backup: can now be downloaded encrypted with its own password (More → Backup → encrypt the backup) and restored again with that password.

Version 1.11.8

November 2, 2026

New

  • Logo: the sun is now in the energy flow's green instead of gold.

Version 1.11.7

November 2, 2026

Fixed

  • Heating: switching the control off while an own override (preheating or setback) was still running sometimes failed to cancel it, because the check compared against the wall clock instead of the planned time.

Version 1.11.6

November 2, 2026

New

  • Access protection settings: a list of all signed-in devices (device type and last activity), so you as the password holder can see who is signed in and log out individual devices – in addition to the existing log-out-everywhere.

Version 1.11.5

November 2, 2026

New

  • Heat pump report (EEBus): power or energy now shows exactly like “by module array”, with day/week/month/year. When it offered runs and what happened still shows below it.

Version 1.11.4

November 2, 2026

Fixed

  • Report by device: the heat pump is now recorded through EEBus, not the old evcc coupling that no longer updates. The day values' autarky could wrongly show 0 % with heavy grid charging – fixed together with the charging bug above.

Version 1.11.3

November 2, 2026

New

  • Own app icon: the sun from the MyAmpere design instead of a house with a solar panel.

Version 1.11.2

November 2, 2026

Fixed

  • Grid charging: a running charge kept its current quarter in the plan even after the battery had reached its target – the battery was charged from the grid past the target instead of discharging.

Version 1.11.1

November 2, 2026

Fixed

  • EEBus helper: its own port 4715 instead of 4712, which evcc takes for its EEBus; otherwise the helper did not start next to evcc.

Version 1.11.0

November 2, 2026

New

  • EEBus: the automatic hot water start first checks with the solar forecast and the expected consumption whether the surplus lasts for the whole run, and waits otherwise. The result shows under devices → heating.

Version 1.10.0

November 2, 2026

New

  • Heat pump through EEBus: it shows in the energy flow with its power and says “ready” as soon as it offers a run (e.g. hot water). Devices shows the offer with a “start now” button, the report when it offered runs, its power and what was started or refused.

Version 1.9.0

November 2, 2026

New

  • Start page: day values in smaller tiles with the icons of the energy flow and arrows for the direction; “self-sufficient” as a split bar with “from the grid”.
  • Heating, EEBus: the automatic start of the hot water run can be switched on and off apart from the connection (off until you switch it on).

Version 1.8.4

November 2, 2026

Fixed

  • iPhone: as a home screen app the menu bar no longer scrolls up with the page after the keyboard was open (a bug in Safari from iOS 26). The page now scrolls in an area of its own there.

Version 1.8.3

November 2, 2026

Fixed

  • Start page: the card of the next grid charge has its own icon, a pylon with a clock.

Version 1.8.2

November 1, 2026

Fixed

  • Start page: while charging from the grid, the card shows until when the current window runs and how many kWh it charges at which average price.

Version 1.8.1

November 1, 2026

Fixed

  • Start page: the next planned grid charge is now a card of its own with an icon right below “self-sufficient”, with start time, amount, price and saving.

Version 1.8.0

November 1, 2026

New

  • Own EEBus helper: myAmpere pairs directly with the heat pump, without Home Assistant. It shows its power and, on solar surplus with a full battery, starts a run the heat pump offers (e.g. hot water). Home Assistant is only needed for the room temperature now.
  • Start page: the current price shows next to “import”, and a card shows the next planned grid charge with time, amount, price and saving. A tap opens “grid charging”.
  • Report: in “by device” and “by module field” a tap or the mouse on the chart shows how much each device or module field had at that time.

Fixed

  • Ampere.StoragePro E3 (“ASP-12KW-…”): the rated power is taken from the model name, so the maximum power for grid charging is right (12 instead of 10 kW).

Version 1.7.0

November 1, 2026

New

  • Heating through Home Assistant: pre-heat in the cheapest block of the day and set back in expensive hours with an empty battery, through the heating's time-limited override (myVAILLANT: quick veto). With master switch, test mode and control log; the owner's own overrides are left alone.
  • Optional EEBus through a bridge in Home Assistant: show the heat pump's power and allow a run on solar surplus.
  • Devices: own section “heating”; heat pumps from evcc show there instead of under wallbox.

Version 1.6.0

November 1, 2026

New

  • Optional extension “consider the weekday”: a consumption profile of its own for each weekday from the last four weeks. So the charging plan expects e.g. the heat pump's legionella program on Sunday noon and charges or holds the battery for it.

Version 1.5.0

November 1, 2026

New

  • Prepayments: enter grid power and feed-in by hand for times without readings, e.g. the months before commissioning. The entries count in energy and cost and replace the estimate for those days; several entries for the same days are added up.

Version 1.4.0

November 1, 2026

New

  • Optional extension “hold the battery”: in cheap quarters the battery does not discharge, the house buys from the grid and solar surplus still charges it, so the energy stays for later, more expensive times. Only when it saves money over the whole period; shown as “held” in the plan. Through the inverter's remote control (FoxESS), with master switch, test mode and control log.

Version 1.3.1

October 31, 2026

Fixed

  • Remote access: after an update the public address was sometimes unreachable (“Bad Gateway”) until the Tailscale helper was restarted. It now reconnects by itself as soon as myAmpere was started anew.

Version 1.3.0

October 31, 2026

New

  • Push notifications of this app (Web Push): switch them on on every device, without ntfy or Home Assistant. On iPhone with the app on the home screen (iOS 16.4 or later). Messages are encrypted for each device; the same events as for ntfy apply.

Version 1.2.0

October 30, 2026

New

  • Optional extension “consumption by outdoor temperature”: measurements and temperatures of the past weeks show how much more the house uses per degree of cold; the plan adjusts each day's expected consumption to the temperature forecast. Temperature from Open-Meteo, heating limit adjustable.

Version 1.1.2

October 30, 2026

Fixed

  • BMW data stream: if the one connection allowed per account is taken (code 151), the app says so and tries again only every 15 minutes.

Version 1.1.1

October 30, 2026

Fixed

  • BMW data stream: connects with MQTT 5 first as BMW expects; if BMW refuses, the app shows the refusal code.

Version 1.1.0

October 30, 2026

New

  • New data source for cars: BMW CarData with data stream. Login with the client ID from the MyBMW portal and a code confirmed at BMW; the values arrive live as soon as the car is active.
  • Overview of the BMW data stream on the cars page: connection, last message and all received values (without location).

Version 1.0.0

October 30, 2026

New

  • Price source for dynamic tariffs: Tibber (with an own access token) or evcc instead of exchange price plus surcharge.
  • Solar forecast from Forecast.Solar for up to four roof planes, compared with the measured generation.
  • Grid charging “with forecast”: plans with prices, solar forecast and usual consumption and charges only when it pays off.
  • Charging plan with charts (values at the cursor) and a table slot by slot.
  • Optional extensions: minimum state of charge in the morning when little sun is expected, share of the solar forecast, partial charging and efficiency.
  • Claude access: read access for analyses with Claude through a secret address (MCP).
  • Remote access with an own Tailscale helper, optionally also on the internet (Tailscale Funnel).
  • Own name “myAmpere”, own logo and “Dashboard” as start page.
  • Updates of the original project are taken over and checked twice a day.
