Which devices work with myAmpere?

Here you see which devices myAmpere shows and controls today and what is in progress. The status of each device, with source, is described in the device documentation of the repository.

Which device you have is on the type plate of the storage system, the inverter or the wallbox. The sales name is usually on the offer or the invoice.

What "planned" means

A planned device has an issue in the repository, but no date yet. Reading the values usually comes first, then control.

Do you have such a device and can test? Then please write in the issue: which device according to the type plate, the firmware and what you observe. Leave out personal data such as serial numbers.

Details, registers and sources for each device are in docs/devices/ in the repository.
