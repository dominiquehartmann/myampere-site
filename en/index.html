Solar and battery storage at a glance, without a manufacturer cloud.

myAmpere reads the values directly from the inverter on your home network and stores them on your own computer. No account and no manufacturer server are needed. On a smartphone you add the page to the home screen, and it then behaves like an app.

The demo shows an invented system and runs only in your browser.

Who is myAmpere for?

Supported devices

  • FoxESS H3, newer firmware: monitoring and control. Monitoring and control confirmed.
  • FoxESS H3, older firmware / H3 Smart / H3 Pro: monitoring and control. Not yet confirmed.
  • SAJ H2 / HS2: monitoring and control. Monitoring confirmed and in daily use on a "3P-X E2" (older "Ampere.StoragePro"); of the control only changing the backup reserve confirmed so far; H2, HS2 and AS2 not yet confirmed.
  • Solarmax MAX.STORAGE ("AMPERE.Storage"): monitoring only. Not yet confirmed.
  • M-TEC Energy-Butler GEN3: monitoring only. Not yet confirmed.
  • Senec.Home V3 / V2.1: monitoring only, chosen in the setup. Not yet confirmed.
  • Enphase IQ Gateway with IQ Battery: monitoring only, with an access token from Enphase. Not yet confirmed.
  • Immersion heater, heat pump (SG-Ready): switched on solar surplus via a Shelly relay or web addresses. Not yet confirmed.
  • Immersion heater my-PV AC ELWA-E, AC ELWA 2, AC THOR: continuously adjusted to the solar surplus. Not yet confirmed.
  • FoxESS AC EV Charger ("Ampere.ChargePro"): monitoring, control only after you agree in the app. Monitoring partly confirmed (idle, on one charger of an EKD system); control not yet confirmed.
  • Weidmüller AC SMART ("AMPERE.Charge"): monitoring only. Not yet confirmed.
  • go-e Charger: monitoring only. Not yet confirmed.
  • Portable dé wallbox (Tuya Wi-Fi): monitoring and control in the home network. Monitoring confirmed; control not yet confirmed.
  • Wallbox through evcc: monitoring and operation through evcc. Not yet confirmed.

The app detects which device you have during setup. The connection uses Modbus TCP. Which devices are confirmed is described in the device documentation on GitHub.

Setup

You start myAmpere once with Docker. The app then guides you through setup: find the inverter, enter the battery and tariff, run the diagnostics.

For the installation you need a computer that runs all day on the home network, for example a Raspberry Pi, a small server or a virtual machine on Proxmox.

Features

Live view

What the solar modules deliver now, what the house uses, whether the battery is charging or discharging and how much goes to the grid. Also wallbox and immersion heater.

Report

Power curve over the day, energy per 15 minutes, hour, day, week, month and year, yield per module array, temperature history and CSV export, with self-sufficiency, self-consumption and estimated savings.

Battery and health

Set the backup reserve, charge limits and operating mode. Full cycles, efficiency and cell temperatures show the condition of the battery.

Charging from the grid

The battery charges in the cheapest quarter hours, in a fixed time window, or with a forecast from electricity prices, solar forecast and usual consumption. Also quick charge and holding the battery in cheap times.

Tariffs and forecast

Fixed or dynamic tariff with exchange or Tibber prices. Solar forecast from Forecast.Solar for up to four roof planes, compared with the measured generation. Advance payments and their status.

Heating and heat pump

Pre-heat when power is cheap, set back when it is expensive. A heat pump with EEBus shows its power and readiness in the app.

Wallbox and car

Wallboxes through evcc, charging plans with repetition, time to target. The portable 11 kW wallbox "dé" can be operated locally. Car data for the Volkswagen group, BMW and MINI, depending on the connection.

Home Assistant and interface

As an app in the Home Assistant sidebar, or through the integration via HACS. An encrypted interface for other apps, with an access token for each app.

Notifications and diagnostics

Notifications via ntfy, e-mail or web push, for example when the inverter is unreachable or the battery is full. A diagnostics run checks registers and connection and creates a report to share.

Access protection

Password, two-factor sign-in with an authenticator app, list of signed-in devices, sign-in log and a limit on repeated failed attempts. Access from outside through your own Tailscale network.

How it works

Installation

myAmpere is installed from the source code of this repository with Docker Compose. The same steps are in the README.

  1. Prepare the computer

    You need a computer with Linux, Docker and Docker Compose that runs on the same network as the inverter. The inverter must have Modbus TCP switched on.

  2. Get the source code

    In a terminal on the computer, get the repository and change into the folder:

    git clone https://github.com/dominiquehartmann/myampere.git && cd myampere

  3. Start

    In the myampere folder, build and start the container:

    docker compose up -d --build

    The first build takes a few minutes. Afterwards the app is reachable at http://<server-IP>:8090.

  4. Set up in the browser

    Set an administrator password, enter the inverter's address under More → Connection, run the diagnostics once under More → Diagnostics and enter the battery capacity under More → My system. Leave the master switch on "View only" at first.

Detailed steps with folders, permissions, configuration and troubleshooting: README in the repository (English) and README.de.md (German).

Configuration

Most settings are made in the app under More. A configuration file is optional: copy config.example.yaml to data/config.yaml and adapt it. Every value can also be set with an environment variable.

Updates

Updates come from the repository. In the myampere folder, update and rebuild:

git pull && docker compose up -d --build

Home Assistant

Two ways: myAmpere as an app in the Home Assistant sidebar, or the integration through HACS. The integration only works while a myAmpere server runs and never talks to the inverter directly. Guides are in the repository at docs/homeassistant-app.de.md and docs/homeassistant.md.

Security

Control is switched off at first

After installation myAmpere only reads. To change settings on the inverter, switch the master switch to "Test" or "Active". In test mode it only logs what would happen.

Access

On the home network anyone can view the values. Changes need a password. From outside you reach the app only through your own Tailscale network. Do not expose the app directly to the internet.

Contribute

Bug reports, requests and device feedback are welcome. A short issue description helps most, and for devices a diagnostics report.
